**Cyber Secure India** - A modern, educational website built with React + Vite + TailwindCSS to spread cybersecurity awareness.
> This project is focused on skill enhancement, showcasing ability to design modular UI/UX, implement theme toggling, and integrate authentic aybersecurity content.

---

## ✨ Features

- 🌗 **Dark/Light Theme Toggle** with custom CSS classes  
- 📱 **Responsive Layouts** for all devices  
- 📚 **Resources Page** linking to trusted cybersecurity sites (NIST, OWASP, Microsoft, VirusTotal, Wireshark, KeePass, OpenVPN)  
- 🎯 **Interactive Quiz** to test and reinforce knowledge  

---

## 🚀 Features 

#### **🌐 Navbar**
- Fixed top-center position with glassmo
- Responsive navbar with glassmorphism effect (desktop top‑center, mobile dropdown).
- Central Cyber Secure India emblem/logo with glowing aura.
- Theme toggle using `isDark` variable (light vs dark).
- Hero section with heading, subtext, and Learn More button.

#### **🔐 Security Page**
- Dark theme with glowing shield icon.
- Highlighted sections for Data Protection, Financial Security, Identity Safety, and Threat Awareness.
- Neon glow accents (green, blue, purple) for futuristic look.
