**Cyber Secure India** - An educational website created to spread awareness about cyber attacks and online safety. The goal is to help users understand risks and adopt secure digital practices.

---

## ✨ **Features**

#### 🌐 **Responsive Navigation**  
- Gradient background navbar with logo
- Smooth scroll navigation across sections 
- Mobile‑friendly dropdown menu 
- Light/Dark theme toggle  

#### 🏠 **Dynamic Home Page**  
- Prominent Cyber Secure India title  
- Logo image with clean design  
- "Learn More" call‑to‑action button  
- Typewriter effect tagline for engaging UI  
- Theme‑aware styling for consistency  

#### 🛡️ **Security Awareness Module**  
- Pages on cyber security best practices  
- Detailed sections on access control and network security  
- Interactive quizzes to test and improve user knowledge  
- Practical tips for everyday online safety  

#### 🚨 **Emergency Guidance**  
- Quick‑access page for urgent cyber help  
- Step‑by‑step instructions for immediate response  
- Links to trusted cyber emergency resources  

#### 📚 **Resource Center**  
- Curated guides and references  
- External links to verified cyber security organizations  
- Downloadable learning materials for deeper study  

#### 📞 **Contact & Footer**  
- Organized footer with essential links  
- Contact information for queries and support  
- Easy navigation back to main sections

---

## 🛠 **Tech Stack**

- **Frontend**: HTML, CSS, TailwindCSS, JavaScript  
- **Framework**: React + Vite for fast and modular development  
- **UI/UX**: Responsive design, theme toggling (light/dark), gradient styling, typewriter effects  
- **Version Control**: Git & GitHub for collaboration and project management  
- **Data & Content**: Structured pages for Security, Emergency, Resources, and Contact information

## 🔩 **Installation & Usage**

1. Clone the repository
```bash
git clone https://github.com/username/cyber-secure-india.git
```
2. Navigate to the project folder
```bash
cd cyber-secure-india
```
3. Install dependencies
```bash
npm install
```
4. Run the development server
```bash
npm run dev
```
